Chandelle

Envoyer une inspiration à Chandelle

Sur Android avec Chrome, installez l’application depuis une adresse HTTPS accessible sur votre téléphone.

Préparation de la réception…

  1. Ouvrez le menu de Chrome puis « Installer l’application » ou « Ajouter à l’écran d’accueil » si l’option est proposée.
  2. Dans Instagram ou TikTok, ouvrez « Partager », puis les autres applications ou « Plus ».
  3. Choisissez Chandelle, sélectionnez votre profil et confirmez l’import.

Si l’application source envoie seulement un lien, ajoutez le fichier vidéo obtenu avec autorisation, ou enregistrez une description comme piste à confirmer. Aucun contenu n’est téléchargé à partir du lien.

Sur iPhone ou si Chandelle n’apparaît pas

La réception native par une PWA n’est pas disponible dans tous les navigateurs. Copiez le lien puis ouvrez l’import manuel dans Chandelle. Une application native serait nécessaire pour proposer une extension de partage iOS.

Vos partages en attente

Avant votre confirmation, le contenu reste sur cet appareil. Cinq partages maximum, supprimés après import ou annulation. Ils expirent après 24 heures et sont nettoyés lors de la prochaine ouverture ou réception. Le navigateur ne permet pas de garantir une suppression à heure fixe lorsqu’il est fermé.

Le partage Android réel reste à tester sur votre téléphone. Le site local 127.0.0.1 de l’ordinateur n’est pas accessible directement depuis le téléphone.
